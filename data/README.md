# مستندات داده‌های NHANES 2021-2023

این پروژه از داده‌های عمومی و رسمی مرکز کنترل و پیشگیری از بیماری‌ها (CDC/NCHS) در دوره اوت ۲۰۲۱ تا اوت ۲۰۲۳ استفاده می‌کند.

## فایل‌های مورد استفاده:
۱. **Demographics Data (`DEMO_L.XPT`):**
   - متغیرهای مورد استفاده: `SEQN` (شناسه یکتا)، `RIAGENDR` (جنسیت)، `RIDAGEYR` (سن)، `WTMEC2YR` (وزن نمونه‌گیری معاینه بدنی)

۲. **Body Measures (`BMX_L.XPT`):**
   - متغیرهای مورد استفاده: `SEQN`، `BMXBMI` (شاخص توده بدنی / BMI)

۳. **Sleep Disorders (`SLQ_L.XPT`):**
   - متغیرهای مورد استفاده: `SEQN`، `SLD012` (مدت‌زمان خواب معمول در شبانه‌روز)

## منبع رسمی دانلود:
- درگاه داده‌های NHANES 2021-2023: https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?Cycle=2021-2023

## راهنمای بازسازی داده تحلیلی:
فایل‌های خام با فرمت SAS (`.XPT`) دانلود شده و توسط کدهای پوشه `src/` بر پایه کلید مشترک `SEQN` ادغام و فیلتر سنی (بالای ۲۰ سال) اعمال می‌گردد.
